# ⚓ SHIPYARD — платформа акселерационной программы

Реализация платформы по «Концепции программы v1.1»: 8 недель от идеи до продукта
через project-based изучение Claude Code внутри полного цикла SDLC.
Дизайн — в стиле Apple (системная типографика, белые поверхности, frosted-glass
навигация, скруглённые карточки).

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Лендинг: позиционирование «не курс, а команда», программа 8 недель с gates, ритм недели, уровни верфи, 3 уровня безопасности, тарифы Solo/Pro/Venture, Demo Day, FAQ |
| `app.html` + `assets/app.js` | Платформа участника (SPA, состояние в localStorage) |
| `assets/styles.css` | Общая дизайн-система |

## Разделы платформы

- **Обзор** — текущая неделя, уровень, очки, задачи недели, ритм ПН–ПТ
- **Трек проекта** — 9 фаз SDLC (недели 0–8) с задачами, артефактами и gates G1–G5; очки за проверяемые артефакты
- **Безопасность** — интерактивный чек-лист OWASP: уровень 1 (чек-лист) и 2 (сканирование) всем, уровень 3 (ручной аудит) — Pro/Venture; кольцо готовности к G4
- **Юридический трек** — параллельная дорожка документов недель 0–7
- **Стена демо** — публикация пятничных демо (+50 очков, серия ×1.1), голосование за демо потока
- **Лига** — мини-группа из 8 участников, лидерборд, правила начисления очков
- **Demo Day** — обратный отсчёт (старт + 56 дней), чек готовности к сцене по gates, три трека после программы
- **База знаний** — материалы недель (открываются по треку), готовый шаблон CLAUDE.md, библиотека промптов вайб-кодинга
- **Эксперты** — 8 направлений пула; индивидуальные слоты видны только на Pro/Venture, SLA ментора 4 раб. часа
- **Профиль** — уровень верфи (Sketch → Captain), 6 бейджей, редактирование данных, сброс демо-прогресса

## Геймификация (по документу)

Очки только за проверяемые артефакты: демо +50, интервью +30, пункт ИБ +10,
gate +100, LOI/первый платёж +200, серия из 3 демо — множитель ×1.1.
Уровень отражает стадию продукта, а не время в программе.

## Запуск

**С бэкендом (полноценный режим):**

```
node server/server.js        # Node ≥ 22, зависимостей нет
```

Один процесс отдаёт и API, и фронтенд: http://localhost:8787.
Аккаунты (scrypt-хэши паролей, HMAC-токены на 30 дней), прогресс, демо и голоса
хранятся в SQLite (`server/data/shipyard.db`, создаётся автоматически вместе
с сид-потоком из 7 участников). Порт — env `PORT`, секрет — env `SHIPYARD_SECRET`
(иначе генерируется в `server/data/.secret`).

API: `register/login`, `me` (GET/PUT), `toggle` (задачи/ИБ/юртрек с серверной
валидацией и начислением очков), `demos` + `vote`, `league`, `health`.

**Без бэкенда (статика):** открыть `index.html` — фронтенд проверяет
`/api/health` и, не найдя сервер, работает на localStorage (так живёт версия
на GitHub Pages). Чтобы страница на Pages ходила в удалённый бэкенд, задайте
в `app.html` перед подключением `app.js`:
`<script>window.SHIPYARD_REMOTE_API = "https://ваш-бэкенд";</script>`
