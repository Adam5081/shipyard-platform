# Дизайн-система Taulau

Стиль — «как у Apple»: много воздуха, крупная типографика, сдержанные
цвета, один акцент. Всё на русском. Логотип — греческая τ (assets/logo.svg).

## Токены (уже в styles.css, не изобретать новые)

- Акцент: `--accent` #0071e3 (синий), пара к нему — бирюза #30b0c7.
  Градиент акцента: `linear-gradient(135deg, var(--accent), #30b0c7)`.
- Текст: `--ink` (почти чёрный), `--ink-2` (серый), `--ink-3` (светло-серый).
- Фоны: `--bg` (белый), `--bg-alt` (светло-серый), `--bg-dark` (тёмные секции).
- Радиусы: `--radius-m` для панелей/карточек, 100px для чипов и кнопок.
- Успех — `--green` #34c759, тревога — #e0a33a. Красный почти не используем.

## Композиция лендинга

- Секция = `.section` + `.wrap` (или `.wrap-narrow center` для коротких).
  Ритм: `eyebrow` (мелкий заголовок-надстрочник) → `headline` (с <br> на
  две строки) → `sub` (серый подзаголовок) → контент через 48–56px.
- Тёмные секции (`.section-dark`) — не чаще, чем через одну; в них eyebrow
  красится в #30b0c7.
- Карточки — `.card` сеткой `grid-3`/`grid-2`; на мобиле всё складывается
  в одну колонку (уже настроено в @media 640).
- Интерактивная лента статов: единый светло-синий #e9f2fc, заголовки
  акцентом, стрелка ⌄, активная кнопка — градиент акцента. Новые
  раскрывашки делать по этому же образцу (`.stat` + `.stat-panel`).

## Анимации («сочность», по мотивам habr 470223)

- Появление контента — класс `.reveal` (IntersectionObserver добавляет `.in`).
- «Дышащие» CTA — `.btn-breathe` только на ГЛАВНОЙ кнопке блока, не на всех.
- Переходы 0.2–0.35s ease; всегда уважать `prefers-reduced-motion`.
- Пиксель-сцены рисует game.js (canvas, imageSmoothing off) — DOM-оверлеи
  поверх канваса, а не рисование текста внутри него.

## Подводные камни (собраны из реальных ошибок)

1. **Версия ассетов**: любые правки styles.css/app.js/game.js/demo.js —
   БАМПНУТЬ `?v=N` во всех четырёх html (admin, app, index, vibe-check),
   иначе прод покажет недельный кэш.
2. **Мобильную вёрстку проверять только через iframe шириной 390px** —
   headless Chrome на Windows не сжимает окно уже ~500px и врёт.
3. **rAF в headless-скриншотах замирает через ~1с** — анимации проверять
   форс-позой (руками задать состояние), а не ожиданием.
4. **Таблицы на мобиле запрещены** — только карточки или скрытие колонок
   (история: «Слот» и «Очки» уезжали за экран, клиент решил, что сломано).
5. **Заголовки в узких кнопках/колонках** — не давать `overflow-wrap:
   anywhere` (рвёт «Безопасность» посреди слова), лучше уменьшить шрифт.
6. **Геймификация с очками/лигой — этап 2**: на лендинге НЕ упоминать
   очки, лигу, призы (решение Адилета 17.08.2026). В кабинете — можно.
7. **Скрытые фичи** — соцразделы кабинета за флагом `SHIPYARD_FLOW_UI`
   в assets/config.js; на лендинге их не рекламировать, пока флаг false.
8. Тексты — без англицизмов, где есть русское слово; «вы» со строчной;
   тире — длинное «—».
